📊 Umang Ecommerce Sales Dashboard (Power BI)

This project presents an interactive Power BI dashboard built using two Excel datasets: Orders and Details. 
The goal was to analyze ecommerce sales performance, customer behavior, and profitability trends.

Key Highlights:
Cleaned and transformed raw data from multiple Excel files using Power BI and preprocessing techniques.
Created data models to combine orders and transaction details for comprehensive analysis.
Designed an interactive dashboard with filters (quarter, state) to explore data dynamically.
Visualized key metrics such as total profit, sales amount, quantity, and average order value.
Analyzed trends across months, product sub-categories, payment modes, and customer segments.

Insights Delivered:
Identified top-performing product categories and high-value customers.
Tracked monthly profit fluctuations to understand seasonal trends.
Analyzed payment preferences (COD, UPI, Credit Card) and their impact on sales.

Tools Used:
Power BI
Excel
Data Cleaning & Data Modeling
